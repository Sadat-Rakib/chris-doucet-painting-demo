# Chris Doucet Painting and Drywall Repair — independent website concept

A bespoke responsive static website. No framework runtime, paid services or backend.

## Run

Requires Node 20+. Run npm run build to validate local references and create dist/. Run npm run dev to preview at http://localhost:4173.
